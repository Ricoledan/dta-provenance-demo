## About the Data & Trust Alliance

The Data & Trust Alliance is a nonprofit organization working to build trust in data
and technology through practical standards and shared resources. Their Data Provenance
Standards provide a common framework for documenting the origin, processing, and
intended use of datasets.

## How This Project Uses DTA Standards

This demonstration project implements the full DTA v1.0.0 specification with all 22
required and optional fields. We provide both Git-native and blockchain-based
implementations to help practitioners understand different approaches to maintaining
data provenance.
